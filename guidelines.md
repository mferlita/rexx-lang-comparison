*Inspired by the [guidelines](https://github.com/smarr/are-we-fast-yet/blob/74306fec151070fd07157cefeacf19e7e0bcdc89/docs/guidelines.md) for the Are We Fast Yet? benchmark project.*

*This is still under construction...*

The goal of this project is to provide a fair comparison of syntax across 
programming languages in relation to the Rexx family of languages. In order to 
do this, programs should be as identical as possible while using each language 
as idiomatically as possible. If available, code should pass a linter to ensure 
some consistency. I will not be accepting any AI generated code. There are 
several reasons why, from environmental to copyright concerns. Also, given that 
this platform is primarily for community and collaboration, I'd like to 
emphasize that for this project.

So, to restate:

#### Programs Should Be As Identical As Possible

#### Use Each Language As Idiomatically As Possible

#### Code Should Pass A Linter If One Is Available

#### No AI Generated Code
